# Usage
you will need:
- Wii
  - Homebrew Channel or other way to launch DOL
  - IOS58 (Comes with 4.3)
- one of the following:
  - Oculus Rift DK1
- way to convert wii AV to HDMI
  - Wii2HDMI works well
  - Wii U works but i reccomend using a utility to change the output viewport to 704x480 (I think by default it is around 672x456)

connect dk1 to wii according to this diagram

<img width="856" height="563" alt="image" src="https://github.com/user-attachments/assets/39903997-3392-404e-8263-26e44d415ad5" />

with the dk1 powered on , launch the program. you can press RESET on the console to recenter, or - on a wii remote

## note
DK1 display seems to show about 680x480 of the output area. the demo outputs to 704x480 area but it seems to work well enough so i didn't bother changing it
